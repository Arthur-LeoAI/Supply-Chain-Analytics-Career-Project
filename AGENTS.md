# Project Goal

This is a portfolio and learning project for Supply Chain Analytics.

The goal is not only to build working software, but also to help the owner
learn SQL, demand planning, inventory planning, Python and BI.

# Working Rules

1. Do not implement large features without first explaining the approach.
2. Prefer readable SQL over unnecessarily clever SQL.
3. Explain supply-chain assumptions before implementing them.
4. Clearly distinguish observed data from simulated data.
5. Do not fabricate business data.
6. Preserve reproducibility.
7. Add comments only where they improve understanding.
8. Prefer incremental changes.
9. Never silently change business logic.
10. Keep the project suitable for a public GitHub portfolio.
