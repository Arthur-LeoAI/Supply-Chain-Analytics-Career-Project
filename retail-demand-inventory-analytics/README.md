# Retail Demand and Inventory Analytics

A portfolio and learning project for supply chain analytics, including SQL, demand planning, inventory planning, Python, and BI.

## Project structure

- `data/raw/`: source data, with provenance documented before use.
- `data/processed/`: reproducible outputs derived from raw data.
- `sql/ddl/`: database schema definitions.
- `sql/analysis/`: analytical queries.
- `sql/views/`: reusable database views.
- `notebooks/`: exploratory and documented analysis.
- `dashboard/`: BI dashboard files and assets.
- `docs/`: methodology, assumptions, and data documentation.
- `src/`: reusable Python source code.

Observed and simulated data should be clearly labeled. No business data is included in this initial structure.
